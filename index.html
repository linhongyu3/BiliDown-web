关于 Bilidown

Bilidown

版本 1.0.0

Bilidown 是一个 B站视频信息解析工具，支持解析视频基本信息、分P列表、多清晰度选择，以及直接播放或跳转观看。

本项目为纯前端实现，不存储任何用户数据。视频数据通过配置的 API 地址获取。
